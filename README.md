# Student Registration and Result Management System

A beginner project that opens directly to the student details form. Use the side menu to view student records or open Result Management. The Result Management page contains both the marks form and Student ID search.

## Technologies

HTML5, CSS3, JavaScript and browser LocalStorage.

## Files

- `index.html` - forms, side menu and tables
- `style.css` - page colors and responsive layout
- `script.js` - saving records, marks calculation and search

## Run

Open `index.html` in a browser, or open the folder in VS Code and choose **Open with Live Server**. Add student details before entering that student's marks.

Student and result information is saved in LocalStorage in the current browser.
